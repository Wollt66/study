# Travel-Planning 实践

## 实践名称
智能行程规划

## 分类
MCP实践

## 案例说明
通过 MCP 集成高德地图，实现智能行程规划。

## 目录结构
```
Travel-Planning/
├── README.md
├── .codeartsdoer/
│   └── mcp/
│       └── amap/              # 高德地图 MCP 配置
│           └── .env.example
└── src/
    └── LOCAL_MATERIALS.md
```

## 使用说明

### 前置条件
- 已安装华为云码道
- 已配置 MCP 环境

### 操作步骤
1. 配置高德地图 API Key
2. 启用 MCP 集成
3. 使用码道进行智能行程规划

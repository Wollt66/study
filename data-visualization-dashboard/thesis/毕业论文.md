# 基于 React 与 ECharts 的数据可视化大屏设计与实现

---

## 摘要

随着大数据时代的到来，企业每天产生海量业务数据，如何直观、高效地展示这些数据成为重要课题。传统的数据表格形式难以快速发现数据背后的规律与趋势，数据可视化大屏通过图形化手段将数据转化为图表、仪表盘等视觉元素，支持多维度联动分析，已广泛应用于指挥中心、运营监控、企业展示等场景。

本文设计并实现了一个基于 React 18 与 ECharts 5 的纯前端数据可视化大屏系统。系统采用 1920×1080 固定分辨率设计，通过 CSS Transform 实现等比缩放适配不同屏幕；使用 Vite 构建工具提升开发与构建效率；通过 ECharts 实现了折线图、柱状图、饼图、横向柱状图等多种图表组件；通过 React 状态管理实现了多图表联动——用户点击柱状图中的某一分类，折线图与饼图自动筛选至该分类数据；通过 setInterval 模拟实时数据推送，每 3-5 秒刷新一次数据，模拟生产环境 WebSocket 实时推送效果。

测试结果表明，系统在 1920×1080 及其他分辨率下均能正确等比缩放渲染，各图表数据更新流畅，多图表联动响应正确，实时数据刷新无明显卡顿。本文的工作为中小型企业的数据可视化大屏建设提供了一套轻量、可复用的前端解决方案。

**关键词**：数据可视化；React；ECharts；大屏设计；多图表联动

---

## Abstract

With the advent of the big data era, enterprises generate massive amounts of business data every day. How to present this data intuitively and efficiently has become an important topic. Traditional data tables make it difficult to quickly discover patterns and trends behind the data. Data visualization dashboards transform data into visual elements such as charts and gauges through graphical means, supporting multi-dimensional linked analysis, and have been widely used in command centers, operations monitoring, and enterprise presentations.

This paper designs and implements a pure front-end data visualization dashboard system based on React 18 and ECharts 5. The system uses a fixed 1920×1080 resolution design and achieves proportional scaling through CSS Transform to adapt to different screens. It uses Vite as the build tool. Various chart components including line charts, bar charts, pie charts, and horizontal bar charts are implemented through ECharts. Multi-chart linkage is achieved through React state management—when the user clicks a category in the bar chart, the line chart and pie chart automatically filter to that category. Real-time data push is simulated through setInterval, refreshing every 3-5 seconds.

Testing results show that the system renders correctly at 1920×1080 and other resolutions, chart data updates smoothly, multi-chart linkage responds correctly, and real-time data refresh has no noticeable lag. This work provides a lightweight, reusable front-end solution for data visualization dashboard construction in small and medium enterprises.

**Keywords**: Data Visualization; React; ECharts; Dashboard Design; Chart Linkage

## 第1章 绪论

### 1.1 研究背景

在数字经济时代，企业每天产生大量业务数据，包括销售额、订单量、用户行为、地域分布等。这些数据如果以原始表格形式呈现，决策者需要花费大量时间阅读和比对，难以快速把握全局态势。数据可视化通过将数据映射为颜色、长度、位置等视觉通道，利用人类视觉系统的快速感知能力，帮助用户在短时间内发现数据趋势、异常和关联。

数据可视化大屏通常应用于以下场景：企业指挥中心实时监控生产经营指标、电商运营大屏展示实时销售数据、城市交通大屏展示路况与流量、舆情监控大屏展示热点事件传播态势。与传统报表不同，大屏强调"一屏观全域"——在单块大屏幕上集中展示最关键的核心指标，支持多图表联动下钻分析。

### 1.2 研究意义

本课题的意义在于：第一，实践价值——设计实现一个可运行的数据可视化大屏，涵盖指标卡片、趋势图、对比图、占比图、地域分布、排行榜等常见大屏组件，具备实际使用价值；第二，技术价值——探索 React + ECharts 的工程化实践，包括大屏自适应缩放、多图表联动、实时数据更新等关键技术；第三，教学价值——作为前端毕设案例，涵盖组件化开发、状态管理、图表库使用、CSS 布局等前端核心技能。

### 1.3 本文主要工作

（1）设计大屏整体布局：顶部标题栏 + 三栏主体布局，左侧指标与占比、中间趋势与对比、右侧地域分布。
（2）实现多种 ECharts 图表组件：折线图、柱状图、环形饼图、横向柱状图。
（3）实现多图表联动：点击柱状图分类，折线图和饼图同步筛选。
（4）实现实时数据刷新：通过定时任务模拟数据推送。
（5）实现大屏自适应：1920×1080 设计稿等比缩放适配任意屏幕。

## 第2章 相关技术

### 2.1 React 18

React 是由 Meta 开发的前端 UI 库，采用组件化开发模式，通过虚拟 DOM 提升渲染性能。React 18 引入了并发渲染（Concurrent Rendering）特性，自动批处理状态更新。本系统使用函数组件 + Hooks（useState、useEffect）管理状态与副作用。

### 2.2 ECharts 5

ECharts 是 Apache 开源的数据可视化库，支持折线图、柱状图、饼图、地图、关系图等数十种图表类型。ECharts 5 新增了深色主题、渐进式渲染、数据缩放等特性。echarts-for-react 是 ECharts 的 React 封装组件，使得在 React 项目中以声明式方式使用 ECharts。

### 2.3 Vite

Vite 是新一代前端构建工具，基于浏览器原生 ES Module 实现开发服务器秒级启动，构建时使用 Rollup 打包。相比 Webpack，Vite 在开发模式下无需打包整个应用，按需编译，大幅提升开发体验。

### 2.4 TypeScript

TypeScript 为 JavaScript 提供静态类型系统。本系统使用 TypeScript 编写，为 mock 数据、组件 props 定义类型，提升代码可维护性。

### 2.5 CSS Grid 布局

CSS Grid 是二维布局系统，适合大屏这种需要精确行列划分的场景。本系统使用 Grid 的 grid-template-columns 和 grid-template-rows 定义三栏主体与各栏内部行高。

## 第3章 需求分析

### 3.1 功能需求

（1）**核心指标展示**：在大屏显著位置展示总销售额、订单数、活跃用户数、转化率四个关键指标，带趋势涨跌标识。
（2）**趋势分析**：展示 24 小时销售趋势折线图，支持多品类对比。
（3）**分类对比**：柱状图展示各品类销售额，支持点击联动。
（4）**占比分析**：环形饼图展示品类销售占比。
（5）**地域分布**：横向柱状图展示全国 TOP10 省份销售数据。
（6）**排行榜**：省份销售排行，带进度条。
（7）**多图表联动**：点击柱状图分类，折线图和饼图同步筛选。
（8）**实时刷新**：数据每 3-5 秒自动刷新，模拟实时推送。
（9）**自适应**：大屏在不同分辨率屏幕上等比缩放，不变形。

### 3.2 非功能需求

（1）首屏加载时间 < 3 秒。
（2）图表切换/联动响应时间 < 200ms。
（3）支持 1920×1080 及以上分辨率。
（4）深色科技风视觉风格。

## 第4章 系统设计

### 4.1 整体布局

大屏采用 1920×1080 固定设计稿，整体分为头部与主体两部分：

- **头部（80px）**：居中显示大屏标题，右侧显示当前日期时间。
- **主体（三栏）**：
  - 左栏（1fr）：数字指标面板（2×2 网格）、品类占比饼图、省份排行榜。
  - 中栏（1.4fr）：24 小时趋势折线图（上）、分类对比柱状图（下）。
  - 右栏（1fr）：全国省份销售分布横向柱状图。

### 4.2 组件设计

系统按职责拆分为以下组件：

| 组件 | 职责 |
|------|------|
| Header | 顶部标题与实时时钟 |
| NumberPanel | 四个核心指标数字卡片 |
| LineChart | 24 小时多品类趋势折线图 |
| BarChart | 品类销售对比柱状图（联动入口） |
| PieChart | 品类占比环形饼图（联动响应） |
| ProvinceChart | 省份销售分布横向柱状图 |
| RankList | 省份销售排行列表 |
| ChartCard | 图表卡片容器（统一边框样式） |

### 4.3 多图表联动设计

联动流程：App 组件维护 `selectedCategory` 状态。BarChart 绑定 ECharts click 事件，点击柱子时调用 `onSelect(category)` 回调。App 接收后更新 `selectedCategory`，并将其作为 prop 传递给 LineChart 和 PieChart。LineChart 和 PieChart 在接收 prop 后过滤自身数据，只渲染选中品类的数据。再次点击同一品类则取消筛选。

### 4.4 自适应缩放设计

使用 `useScreenScale` Hook 监听 window.resize 事件，计算 `scale = min(window.innerWidth / 1920, window.innerHeight / 1080)`，将 scale 应用到大屏容器的 CSS transform: scale()。由于 transform-origin 设为 center，大屏始终居中等比缩放，不变形。

### 4.5 实时数据设计

使用 `useLiveData` Hook，内部通过 setInterval 每 3-5 秒调用 mock 数据生成函数并更新 state。React 状态更新触发组件重渲染，ECharts 通过 notMerge 模式 option 更新图表。

## 第5章 系统实现

### 5.1 项目初始化

使用 Vite 创建 React + TypeScript 项目，安装 echarts 和 echarts-for-react 依赖。配置 vite.config.ts 开发服务器端口 3000。

### 5.2 全局样式

index.css 定义大屏深色科技风主题：背景为深蓝径向渐变（#0d2149 → #060d24），面板边框为半透明蓝色（rgba(0,180,255,0.3)），标题文字使用渐变蓝色。面板四角使用 ::before/::after 伪元素绘制蓝色装饰角。

### 5.3 数字指标面板

NumberPanel 组件使用 useLiveData Hook 每 3 秒刷新一次数据，展示四个核心指标。每个卡片包含标签、大字号数值和趋势涨跌箭头（绿色向上/红色向下）。

### 5.4 折线图

LineChart 组件调用 generateHourlyTrend 生成 24 小时数据，每个品类一条平滑折线。当 selectedCategory 存在时，只渲染选中品类的折线。ECharts 配置中设置 smooth: true 使线条平滑，symbol: 'none' 隐藏数据点以保持视觉简洁。

### 5.5 柱状图与联动

BarChart 组件展示五个品类的销售额。绑定 onEvents.click 事件，点击柱子时调用 onSelect 回调。选中品类的柱子高亮为亮蓝色（#00e4ff），其余为深蓝色（#1a6aaa）。

### 5.6 饼图

PieChart 组件使用环形饼图（radius: ['40%', '70%']）展示品类占比。当 selectedCategory 存在时，只展示选中品类的数据。

### 5.7 省份分布图

ProvinceChart 组件使用横向柱状图（y 轴为类目轴）展示 TOP10 省份数据，柱体使用从深蓝到亮蓝的线性渐变填充。

### 5.8 排行榜

RankList 组件使用 HTML/CSS 实现（非 ECharts），展示前 8 名省份，前三名使用红/橙/黄底色序号，进度条宽度按占最大值比例计算。

# 答辩演示脚本（约 8 分钟）

各位老师好，我的毕业设计题目是《基于 React 与 ECharts 的数据可视化大屏设计与实现》。

**背景（1分钟）**：在大数据时代，企业每天产生大量销售、用户、地域数据。传统表格形式难以快速发现趋势，数据可视化大屏通过图形化手段将数据转化为图表，实现"一屏观全域"，广泛应用于指挥中心和运营监控场景。

**需求（1分钟）**：系统需要展示四类核心指标、24 小时销售趋势、品类对比、品类占比、全国省份分布和销售排行。同时要求多图表联动——点击某个品类，其他图表同步筛选；数据实时刷新；大屏在不同分辨率下等比缩放不变形。

**技术选型（1分钟）**：前端使用 React 18 组件化开发，图表库使用 Apache ECharts 5，构建工具使用 Vite 实现秒级启动，语言使用 TypeScript 保证类型安全，布局使用 CSS Grid 实现精确的三栏划分。

**系统设计（1.5分钟）**：大屏以 1920×1080 为设计稿，顶部是标题栏和实时时钟，主体分为三栏：左栏是数字指标卡片、品类占比饼图和省份排行榜；中栏是 24 小时趋势折线图和品类对比柱状图；右栏是全国省份销售分布。

**现场演示（2分钟）**：
大家现在看到的就是大屏运行效果。左上角四个数字卡片每 3 秒自动刷新，模拟实时数据推送。中间是 24 小时销售趋势折线图，五个品类各一条线。下面是品类对比柱状图——我点击"电子产品"这根柱子，大家可以看到，左边的饼图和中间的折线图都自动筛选到了电子产品这一个品类，这就是多图表联动。再点一次取消筛选。右边是全国 TOP10 省份销售分布，左下角是省份销售排行榜。

**自适应（0.5分钟）**：我现在调整浏览器窗口大小，可以看到整个大屏等比缩放，始终居中显示，不变形——这是通过 CSS transform scale 实现的。

**测试（0.5分钟）**：功能测试覆盖了所有图表渲染、联动、实时刷新和自适应缩放，在 Chrome 和 Edge 下均正常。

**总结（0.5分钟）**：本系统完成了数据可视化大屏的全部核心功能，包括多图表联动和实时数据刷新。不足在于目前使用 mock 数据，未来可以接入真实后端 WebSocket 推送，引入中国地图实现地理可视化。以上就是我的汇报，请各位老师批评指正。
